# 🛍️ E-Commerce Platform for Artisan Women

## Overview

This project is an e-commerce platform developed to support and empower artisan women by providing a digital marketplace where they can showcase, promote, and sell their handcrafted products.

The platform aims to bridge the gap between skilled artisans and potential customers by creating an accessible online shopping experience that promotes financial independence and entrepreneurship.

---

## Problem Statement

Many talented artisan women face challenges in reaching wider markets due to limited access to digital platforms and marketing channels.

This project aims to:

* Provide an online marketplace for handcrafted products.
* Increase visibility for artisan women.
* Support entrepreneurship and financial empowerment.
* Connect customers directly with artisans.

## Installation

Clone the repository:

```bash
git clone https://github.com/Akshara-praturi/ECOM-for-ArtisianWomen.git
```

Navigate to the project directory:

```bash
cd ECOM-for-ArtisianWomen
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
node server.js
```
